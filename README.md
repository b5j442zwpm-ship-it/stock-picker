# בורר המניות

לוח מחוונים בעברית לסינון מניות בארה"ב ובתל אביב, עם ציון לכל מניה ורמת סיכון 1–5.

**זה כלי עזר, לא ייעוץ השקעות.** אף מודל לא חוזה מחירים.

## איך זה עובד
* `scripts/build_data.py` רץ כל יום חול ב-GitHub Actions (אחרי סגירת וול סטריט), מושך מחירים ונתונים פיננסיים מ-Yahoo Finance וכותרות מ-Google News, ומחשב:
  * 7 מרכיבי ציון (מומנטום, תמחור, איכות, צמיחה, אנליסטים, טון חדשות, יציבות) כאחוזונים בתוך הרשימה
  * רמת סיכון מוחלטת 1–5 (תנודתיות, ירידה מקסימלית, בטא, מינוף, גודל חברה)
  * מצב שוק כללי (S&P 500 מול ממוצע 200 יום, VIX, תשואות אג"ח, חדשות)
* התוצאה נשמרת ב-`docs/data.json`, והלוח ב-`docs/index.html` מוצג דרך GitHub Pages.
* הפרופיל (שמרני / מאוזן / אגרסיבי) משנה את משקלות הציון בדפדפן.

## שינוי רשימת המניות
עורכים את `tickers.txt` (שורה לכל מניה, מניות ת"א עם הסיומת `.TA`). שמירת הקובץ מפעילה עדכון אוטומטי.

## הרצה ידנית
בלשונית Actions, בוחרים "Update stock data" ולוחצים Run workflow.
