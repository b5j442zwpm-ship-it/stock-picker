# בורר המניות

לוח מחוונים בעברית לסינון מניות בארה"ב ובתל אביב, עם ציון לכל מניה ורמת סיכון 1–5.

**זה כלי עזר, לא ייעוץ השקעות.** אף מודל לא חוזה מחירים.

## איך זה עובד
* `scripts/build_data.py` רץ כל יום חול ב-GitHub Actions (אחרי סגירת וול סטריט), מושך מחירים ונתונים פיננסיים מ-Yahoo Finance וכותרות מ-Google News, ומחשב:
  * 7 מרכיבי ציון (מומנטום, תמחור, איכות, צמיחה, אנליסטים, טון חדשות, יציבות) כאחוזונים בתוך הרשימה
  * רמת סיכון מוחלטת 1–5 (תנודתיות, ירידה מקסימלית, בטא, מינוף, גודל חברה)
  * מצב שוק כללי (S&P 500 מול ממוצע 200 יום, VIX, תשואות אג"ח, חדשות)
* התוצאה נשמרת ב-`docs/data.json`, והלוח ב-`docs/index.html` מוצג דרך GitHub Pages.
* הפרופיל (שמרני / מאוזן / אגרסיבי) משנה את משקלות הציון בדפדפן.

## בדיקת מניה: לקנות עכשיו / לחכות / לא לקנות
בראש הלוח יש תיבת "בדיקת מניה". בוחרים מניה ומקבלים המלצה אחת מתוך שלוש, עם הסיבות, אחרי 12 בדיקות (`scripts/verdict.py`):

| קבוצה | בדיקות |
|---|---|
| מגמה ותזמון | מגמת מחיר (ממוצעי 50/200 יום, 3 חודשים), נקודת כניסה (RSI, מרחק מממוצע 50 יום) |
| אירועים קרובים | האם יש דוח רבעוני בשבוע הקרוב |
| העסק עצמו | הדוח האחרון מול התחזיות, תמחור מול הסקטור והצמיחה, רווחיות, מאזן ותזרים, צמיחה |
| אנליסטים וחדשות | המלצה ממוצעת ומחיר יעד, טון הכותרות בשבועיים האחרונים |
| סיכון ושוק | רמת סיכון 1–5, מצב השוק הכללי |

* **לקנות עכשיו**: העסק טוב, המגמה עולה, ואין סיבת תזמון לחכות (אין דוח בשבוע הקרוב, המניה לא מתוחה אחרי ריצה).
* **לחכות**: המניה סבירה או טובה אבל התזמון לא (דוח קרוב, עלייה חדה מדי, מגמה לא מאושרת, שוק בלחץ), או שהתמונה מעורבת. ההמלצה אומרת למה בדיוק לחכות, עם מחירי ייחוס.
* **לא לקנות**: עסק חלש ו/או מגמה שבורה, או יותר מדי סימני אזהרה.

הבדיקות משתמשות בספים מוחלטים, כך שההמלצה למניה לא תלויה במניות האחרות ברשימה. זה לא ייעוץ השקעות.

### מניה שלא ברשימה
בלשונית Actions בוחרים **"Add stock (הוספת מניה)"**, לוחצים Run workflow ומקלידים סימול (למשל `SHOP`, או `TEVA.TA` לת"א). אחרי כ-10 דקות המניה מופיעה בלוח עם בדיקה מלאה, ונשארת ברשימה.

## שינוי רשימת המניות
עורכים את `tickers.txt` (שורה לכל מניה, מניות ת"א עם הסיומת `.TA`). שמירת הקובץ מפעילה עדכון אוטומטי.

## הרצה ידנית
בלשונית Actions, בוחרים "Update stock data" ולוחצים Run workflow.
